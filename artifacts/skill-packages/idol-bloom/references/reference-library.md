# Idol Bloom 設計參考庫

來源於 2026-09-30 開啟查核。以下 17 筆都是官方角色網站、工具提供者的教學或標準文件；頁面可能更新。來源摘要用自己的話整理，「練習」與「轉化方式」是本 skill 的教學設計。

角色階段可用 [立繪與生圖](illustration-and-imagegen-guide.md)，建立角色後再用 [主題與場景設計](theme-and-scene-guide.md)推導環境；整組需求則依序接續。只有 Momo 程式案例使用 GitHub 檔案依據；這些指南安裝在 skill 內，外部來源供選讀與查核。

## 怎麼挑參考

| 現在卡住的地方 | 先讀哪裡 |
| --- | --- |
| 完全不知道角色要做什麼 | 1 的個性方法，再搭配 4 或 6 的角色案例 |
| 每張圖都像不同角色 | 2 的輪廓與風格，再定義固定與可變特徵 |
| 沒有設計背景、也不會畫 | 3 的入門方法，先做可修改角色提案；需要圖片再讀立繪指南 |
| 想做歌手或直播型角色 | 4、5；確認模型需求後才讀 9 或 10 |
| 不知道怎麼配色或排官網 | 7、8，再用 12 檢查文字可讀性 |
| 想讓角色動起來 | 11；已有 GSAP 網頁再讀 13 |
| 主題只有一個關鍵字，不知道世界怎麼設計 | 14、15，再使用主題與場景指南 |
| 已有角色，要設計搭配的場景 | 14、15，從現有角色活動推導場所 |
| 想要立繪和背景像同一個世界 | 14，沿用角色摘要再補場景規格 |
| 不會安排背景、角色站位和文案空間 | 16、17，再畫前中後景與留白 |

每次只選與問題有關的參考，避免把整份清單當成學員必讀作業。引用設定與技術內容前開啟對應頁面；網站視覺需另行查看圖像或實際頁面。

## 角色與視覺方法

### 1. 從個性建立原創角色

[CLIP STUDIO PAINT — How to Make Appealing Original Characters](https://www.clipstudio.net/how-to-draw/archives/154434)

- **來源內容**：從角色個性與背景出發，透過服裝、代表圖案、表情與姿勢建立辨識；不必一開始就決定所有細節。
- **練習**：把「溫柔」「急性子」各改寫成一句會說的話和一個動作，再寫外觀。
- **轉化方式**：由行為推導視覺，不直接套用文章中的示範人物。

### 2. 輪廓、比例與畫風

[CLIP STUDIO PAINT — Character Art Styles & Ideas](https://www.clipstudio.net/en/characterart/art-style/)

- **來源內容**：用清楚輪廓、比例、髮型、衣服與配件區分角色；角色群也需檢查一致的風格。
- **練習**：比較兩個不同輪廓的提案。只看小尺寸或黑色剪影時，哪個特徵還在？
- **轉化方式**：固定自己的辨識特徵，允許表情與姿勢變化；不要把更複雜的細節當成更好的設計。

### 3. 不會畫圖時的起點

[CLIP STUDIO PAINT — Introductory Guide to Character Art](https://www.clipstudio.net/en/characterart/beginners-guide/)

- **來源內容**：介紹角色繪製的基本思考與數位繪圖方法。
- **練習**：學員說出三個偏好，agent 整理成一份具體的外觀描述，標示哪些還是暫定提案。
- **轉化方式**：不要求學員先學完繪圖軟體。繪圖描述、圖片 Prompt 與實際圖片分別記錄完成狀態。

## 角色與品牌案例

### 4. 虛擬歌手：Piapro Characters

[Crypton Future Media — Hatsune Miku and Piapro Characters](https://piapro.net/intl/en_character.html)

- **來源內容**：官方介紹初音未來等虛擬歌手、代表色與設定，並呈現 Snow Miku、Sakura Miku 等主題延伸。
- **練習**：為自己的角色寫一個核心活動與一個季節版本，列出變化後仍保留的辨識特徵。
- **轉化方式**：學習「核心身份可以延伸」，自行設計名字、輪廓與主色，不複製初音的造型。

### 5. 角色設定、說話方式與內容活動

[hololive — Usada Pekora 官方角色頁](https://hololive.hololivepro.com/en/talents/usada-pekora/)

- **來源內容**：角色頁介紹兔耳身份、喜好、口頭習慣與直播內容等資訊。
- **練習**：替自己的角色寫一個日常喜好、一句登場招呼與一種可持續的內容活動，檢查是否互相呼應。
- **轉化方式**：借用設定與行為相連的思考；兔耳、胡蘿蔔、口頭禪等具體組合不直接移植。

### 6. 有反差與生活細節的角色

[Sanrio — Kuromi 官方角色頁](https://www.sanrio.co.jp/characters/kuromi/)

- **來源內容**：官方角色介紹與個人資料；可搭配頁面上的官方圖像觀察外觀與介紹的關係。
- **練習**：幫自己的角色加上一個外表看不出的喜好，再寫出能讓觀眾發現它的台詞或動作。
- **轉化方式**：反差可以成為記憶點；角色設定與外觀要重新設計，不換個名字就沿用現有角色。

### 7. 角色主視覺與網站內容層級

[《時々ボソッとロシア語でデレる隣のアーリャさん》官方網站](https://roshidere.com/)

- **來源內容**：動畫官方網站的主視覺、公告與角色相關資訊。
- **練習**：實際開啟頁面，描述第一眼看到的內容與閱讀順序，再為自己的官網畫出簡單區塊草圖。
- **轉化方式**：分析資訊如何安排，不複製網站品牌、角色圖、文案或整套版面。與自己的操作目標無關的裝飾可省略。

## 配色與素材製作

### 8. 從一個喜歡的顏色開始

[Adobe Color — Color Wheel](https://color.adobe.com/create/color-wheel)

- **來源內容**：以基底色與色彩關係建立調色盤，也提供對比與色彩可及性相關工具入口。
- **練習**：用學員喜歡的一個顏色，提出角色主色、背景色與文字色的兩個組合，並說明用途。
- **轉化方式**：角色辨識色與介面功能色分別定義；配色看起來協調，仍需另測文字對比。

### 9. Live2D 插畫分層與補畫

[Live2D Cubism — About Material Separation](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)

- **來源內容**：說明插畫拆成可動部件、補畫動作後會露出的區域，以及編輯用與匯入用 PSD 的差別。
- **練習**：若目標包含 Live2D 模型，列出想動的部位、遮擋關係與需要補畫的區域。
- **轉化方式**：依目標動作決定素材工作，不用一張完整立繪或網頁動畫宣稱已完成模型。

### 10. 3D 角色的姿勢、表情與視線

[VRM — Features and Contents of VRM](https://vrm.dev/en/vrm/vrm_features/)

- **來源內容**：介紹人形角色格式與姿勢、表情、視線等操作的標準化。
- **練習**：有 3D 模型需求時，分別列出待機姿勢、表情與看向哪裡，並確認目標應用是否支援所需版本與功能。
- **轉化方式**：用文件理解模型需求；VRM 檔案存在不等於已完成所有平台的追蹤、口型或直播驗證。

## 互動與驗證

### 11. 讓學員可選擇減少動態

[W3C WAI — Understanding SC 2.3.3: Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)

- **來源內容**：AAA 準則說明非必要的互動觸發動態應可關閉；可利用使用者的減少動態偏好。
- **練習**：替同一個操作寫一般動態與減少動態兩種回應，兩者都保留角色表情和必要訊息。
- **轉化方式**：減少位移或縮放，不把內容與操作一起移除。這裡是動態設計參考，不代表已通過完整 WCAG 評估。

### 12. 角色很可愛，文字也要讀得清楚

[W3C WAI — Understanding SC 1.4.3: Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

- **來源內容**：AA 文字對比要求一般文字至少 4.5:1，符合文件定義的大字至少 3:1；適用範圍與例外依原文。
- **練習**：測角色介紹、按鈕和回應文字在實際背景上的對比。漸層或圖片背景要看文字所在區域。
- **轉化方式**：保留角色色彩，必要時調整介面文字或底色；不要只憑「看起來清楚」宣稱達標。

### 13. GSAP 的響應式與減少動態處理

[GSAP — gsap.matchMedia()](https://gsap.com/docs/v3/GSAP/gsap.matchMedia%28%29/)

- **來源內容**：依媒體查詢建立動畫，條件改變時還原管理範圍內的動畫，可處理桌機、手機與減少動態偏好。
- **練習**：現有專案使用 GSAP 時，檢查切換視窗尺寸與動態偏好後的動畫狀態，以及卸載後的清理。
- **轉化方式**：沿用專案框架。這是 GSAP 實作參考，不要求所有虛擬偶像使用此套件。

## 主題、概念設計與場景構圖

### 14. 角色與環境的概念設計

[CLIP STUDIO PAINT — Concept Art Styles & Ideas](https://www.clipstudio.net/en/conceptart/art-style/)

- **來源內容**：介紹角色與環境概念設計，從個性與背景出發探索造型、服裝、道具；環境也需表達故事與世界設定。
- **練習**：把自己的主題拆成「角色做什麼、穿什麼、帶什麼、在哪裡活動」四句，再找一個共享符號。
- **轉化方式**：先保留角色基準，再推導環境規格；需要模型時才補多角度設定，不為入門圖片一律增加三視圖。

### 15. 不知道主題背景怎麼開始

[CLIP STUDIO PAINT — Introductory Guide to Concept Art](https://www.clipstudio.net/en/conceptart/beginners-guide/)

- **來源內容**：概念設計用視覺呈現故事世界，涵蓋角色、服裝與環境等方向。
- **練習**：由 agent 將「海洋」變成兩個具體場景提案，例如潮汐郵局或夜間燈塔廣播站，說明角色在裡面做什麼。
- **轉化方式**：先選一個能服務角色活動的地點，再定時間、天氣與光線；不靠堆疊主題裝飾代替世界觀。

### 16. 用剪影和遠近層次安排背景

[CLIP STUDIO PAINT — Creating a Dynamic Landscape Composition with Silhouette](https://www.clipstudio.net/how-to-draw/archives/163026)

- **來源內容**：以剪影和構圖探索地景，安排遠近層次與畫面的視覺關係。
- **練習**：先用三塊簡單色面描述前景、中景與後景，再標出角色位置和可放文字的低細節區。
- **轉化方式**：生成前寫清楚布局，生成後檢查；不沿用教學作品中的特定建築與場景。

### 17. 讓角色成為焦點、背景服務閱讀

[CLIP STUDIO PAINT — Tips for Comic and Manga Design](https://www.clipstudio.net/en/comics-manga/design-tips/)

- **來源內容**：討論畫面與閱讀設計，包括調整背景線條、細節和明暗，讓人物更容易被看見；小畫面也需要控制細節。
- **練習**：縮小看角色與背景的合成圖：第一眼是否看到主角？再看手機畫幅，文案是否仍有空間？
- **轉化方式**：將焦點與細節取捨應用到偶像主視覺；官網構圖是本 skill 的推導，不把漫畫方法當成網站技術規格。

## 把 Reference 變成自己的設計

每次參考後，agent 可以幫學員完成這四句：

```text
我觀察到：〔來源中可核對的設定、行為或視覺〕。
我想解決：〔自己的角色目前缺少什麼〕。
我會轉化成：〔自己的身份、圖案、配色或操作〕。
我會這樣檢查：〔縮小辨識、台詞一致、操作或對比測試〕。
```

保留直接來源連結與自己的推導。沒有看過圖片時，不填寫外觀觀察；沒有實測時，不把驗證方法寫成已通過的結果。
