# 立繪與分階段生圖指南

角色立繪、背景、合成圖與表情可以分開製作，也可一次提出整組需求。通常先建立角色基準，場景需求出現時再使用 [主題與場景設計](theme-and-scene-guide.md)；本指南不依賴 Momo 素材。

## 按目前階段選素材

| 使用者這次要什麼 | 從哪裡開始 | 本次交付 |
| --- | --- | --- |
| 新角色／先做立繪 | 角色設定 → 基準立繪 | 角色摘要與指定立繪；場景待後續 |
| 有角色，只做背景 | 查看角色 → 推導場景 → 背景 | 指定背景與場景規格；沿用角色 |
| 有角色與背景，要主視覺 | 查看兩者 → 安排構圖與接觸 | 合成圖；保留兩份原素材 |
| 有角色，只改表情 | 查看基準立繪 → 指定表情 | 指定變體；不需要先做場景 |
| 角色與背景整組 | 角色基準 → 場景構思 → 指定素材 | 依需求完成整組，各圖分開保存 |

前一階段的圖片仍適用時直接重用。只做背景不新增角色變體；只做立繪不補場景圖。文字設定可先支持場景企劃，但視覺匹配與圖像編輯要使用實際圖片。

## 判斷交付是規劃還是圖片

- 「幫我規劃」「給我 Prompt」：交付本次階段的規格與已填好的逐張 Prompt。
- 「先幫我生立繪」「只做背景」：完成並交付指定圖片，之後的階段另依需求處理。
- 「立繪和背景一次做出來」：先有角色基準，再定場景；直接使用可用的圖片工具依序生成、查看與交付。已有整組生成授權時，不為每個素材再次要求確認。
- 「我不會設計，你幫我決定並生圖」：提出可修改的完整方向並繼續生成；標示暫定設定，不把沒有回答當成已確認角色。

已提供的偏好、名字、角色圖與文字優先。需要沿用角色時先實際看圖；缺少必須保留的原圖時請使用者補回，不靠文字假裝還原。缺少工具時交付可直接使用的 Prompt 和待生成清單，明確回報限制，不將規劃標成圖片完成。

## 整組素材的起始組合

下表是素材選單，也是五張完整示例。使用者明確要求整組且沒有指定內容時，可提出這個可修改組合；「生圖」或「設計虛擬偶像」本身不等於要求五張。依本次用途選取，已有素材可直接沿用。

| 檔名示例 | 內容與用途 | 目標比例／背景 | 必須保留 |
| --- | --- | --- | --- |
| `character-base-v1.png` | 全身基準立繪，供網站與後續參照 | 2:3／真正透明 | 頭部到鞋底、全部代表配件、邊緣留白 |
| `background-desktop-v1.png` | 搭配角色主題的獨立場景 | 16:9／完整背景 | 無角色、可站立空間、文字低細節區 |
| `hero-composite-v1.png` | 角色置於場景中的完整主視覺 | 16:9／完整場景 | 使用同一角色和背景、光線透視一致 |
| `character-cheer-v1.png` | 收到鼓勵的表情變體 | 與基準一致／透明 | 只改表情，固定服裝、比例與站位 |
| `character-curious-v1.png` | 好奇或疑惑的表情變體 | 與基準一致／透明 | 只改表情，固定服裝、比例與站位 |

手機官網需要額外場景時加上 `background-mobile-v1.png`（9:16，重新安排地標與留白）；不要默默增加張數。動物、星星或機器人沒有鞋子時，用其完整身體下緣作為基準。

合成圖幫助學員看見整體效果，獨立立繪和背景則供後續排版與互動使用。各張圖分開輸出；除非使用者要素材表，不把五張壓成唯一一張拼貼圖。

## 畫好可重用的立繪

初版寫清楚：全身或半身、視角、姿勢、面向、表情、固定服裝與道具、畫風、光線、留白與背景。完整站姿可採稍微張開的手臂，讓重要配件看得清楚；不必為靜態官網強制使用建模用 T pose。

角色剪影要能辨識，手腳不要被不必要的布料或道具全部遮住。檢查髮型、帽子、尾巴、長耳朵與手持物是否超出畫布。生成後實際查看五官、肢體數量、接觸位置與配件連接，不能只憑 Prompt 判斷成功。

透明背景要使用工具的透明輸出設定。純白底、畫進去的棋盤格、地面與背景圖案都不等於透明；需要投影時另行指定，並檢查邊緣是否殘留場景顏色。生成單張立繪不等於交付分層 PSD、Live2D 模型或 3D 模型。

## 依需求接續製作

以下是整組需求的接續關係；單階段需求只執行相關部分，表情變體不依賴背景完成。

1. **整理角色基準**：從對話或已有交付讀取身份、固定外觀、畫風與本次素材需求。沒有場景需求時，不先指定郵局、夜景或舞台。
2. **建立或重用立繪**：要新圖時生成並查看角色完整性；已有合適圖片時直接沿用。附 [角色摘要](theme-and-scene-guide.md#可接續的角色摘要與場景規格)，只做角色的任務在此交付。
3. **構思並建立背景**：有場景需求時，從角色身份與活動推導場景，再依立繪的畫風、光線與視角製作。需要時附角色圖作為視覺參照，明確要求背景中無人物。只做背景的任務交付背景與場景規格即可。
4. **建立合成圖**：把實際角色圖與場景圖提供給圖片編輯工具，標明角色身份參照與場景構圖參照。安排位置與腳底接觸，不重新隨機設計人物。合成不是像素完全不變的保證，仍需核對。
5. **建立表情變體**：用實際基準立繪作為編輯目標，一次改一個表情。保持畫布、位置、服裝與比例；需要姿勢變化時另行指定。
6. **查看並針對問題修正**：例如配件缺失、背景搶眼、臉部漂移；修改造成問題的項目，保留其他共同規格。沿用原版檔案，修正版使用新的版本名。
7. **整理交付**：展示完成圖片並提供檔案位置，附素材清單、共同規格、Prompt 與檢查結果。部分失敗時保留成功素材，明確列出未完成項目。

「一次取得」指一次提出整組需求後由 agent 依角色優先的順序完成；分階段則交付當前成果與可接續摘要。不要把所有圖片各自從文字重新生成，假定它們自然會是同一角色。

## 可直接使用的整組 Prompt 範例

以下「森林郵差・葉音」是可修改教學提案。agent 應依學員需求改寫，將完整的固定特徵與畫風帶入每張工具 Prompt，不只寫「和上一張一樣」。使用者已提供名字時沿用，不自行替換。

### 第一階段：角色基準

```text
原創虛擬偶像「葉音」：為森林居民送出鼓勵信件的狐狸郵差。
溫和、做事認真但偶爾迷路，想讓觀眾感到被記得。
橘棕狐狸，奶油色口鼻與尾尖，直立尖耳，圓潤但有清楚輪廓。
穿苔綠短斗篷、暖棕郵袋、簡潔短靴，帽沿有一枚葉形別針。
郵袋上的奶油色信封徽章固定保留，不增加其他標誌。
柔和手繪插畫，乾淨外輪廓、細緻但節制的筆觸、簡化陰影。
柔光由左上照入，陰影節制，方便後續搭配環境。
畫風與身體比例作為變體基準；具體場景待角色完成後再設計。
本次不加浮水印、品牌標誌與插畫內文字。
```

### A．透明立繪

```text
依上述完整角色基準生成葉音的全身立繪。
接近平視、正面略轉，站姿穩定，雙手自然放置，溫和微笑。
頭、耳朵、尾巴、帽子、郵袋與靴子完整入鏡，四周留足空間。
直式 2:3 構圖，角色居中，不畫場景、地板與背景裝飾。
真正透明背景，不用白底或棋盤格代替。光線沿用左上柔光。
```

### 第二階段：由角色構思場景

葉音是森林郵差，代表活動是送出鼓勵信；因此本次提案選「郵局前的收信平台」，讓官網像邀請訪客來收信。以完成的立繪為視覺參照，再安排雨後森林、木製投遞窗與低彩度背景。這是新場景提案，不改角色毛色、帽子、斗篷與郵袋。

### B．獨立背景

```text
依葉音的角色設定與提供的實際立繪，生成雨後森林郵局背景。
本次場景規格：木製樹洞郵局、林間投遞窗與小平台，背景低彩度。
角色身份是森林郵差，場景用於邀請觀眾收一封鼓勵信，無角色與人物。
與立繪相同畫風、平視鏡頭、左上柔光、低彩度森林綠與暖棕木頭。
前景少量草葉；中景右側是木製樹洞郵局與可供角色站立的小平台；
後景是薄霧中的林間小徑與遠樹，窗內一點琥珀色暖光。
橫式 16:9，右側中景預留角色空間，左側約三分之一保持低細節。
地面透視清楚，無畫中標題或假文字，不讓葉片和亮點佔滿留白。
角色圖若作為參照，僅取畫風與光線，不將角色畫進背景。
```

### C．合成主視覺

```text
使用附件 A 的角色身份、服裝、比例與畫風，使用附件 B 的場景布局。
將同一位葉音安排在右側平台，腳底與地面相接，光源與透視匹配。
保留左側低細節文案空間，角色臉部與郵袋清楚，背景不搶主角。
橫式 16:9，不增加其他角色、配件、標誌或文字。
```

### D／E．表情變體

```text
以附件 A 的基準立繪為編輯目標。
固定身份、輪廓、毛色、耳朵、帽子、斗篷、郵袋、靴子、光線和畫風。
維持畫布比例、角色大小、頭部位置與腳底位置，真正透明背景。
本次只改表情為：〔D：收到鼓勵後開心微笑／E：好奇地輕抬眉毛〕。
其餘姿勢與服裝保持一致，不增加文字、道具或場景。
```

D 與 E 分別生成。實際呼叫時提供附件並標明作用，不把範例中的「附件 A」當成已經提供的圖片。

## 可用圖片工具的執行方式

優先使用環境提供的原生圖片生成與編輯工具。使用 `image_gen` 時，依當前工具 schema 傳入 Prompt 與透明設定；角色立繪及表情設為透明，背景與合成圖設為不透明。全新圖片不帶虛構參照路徑；編輯時，先查看本機圖片，再提供實際路徑；只有對話中無本機路徑的圖片才使用近期圖片參照方式。兩種參照方式不要同時傳入。

每次工具呼叫對應一個明確素材與變動。指定比例與尺寸是輸出目標，實際結果以檔案為準；工具不支援精確尺寸時，回報實際尺寸與尚需調整的部分，不宣稱符合未測量的規格。

原生工具缺少時不自行改用需要金鑰或付費的 CLI。先說明工具限制並交付整組 Prompt；使用者選擇替代工具後才依其方式執行。圖片編輯使用圖片工具，不自行寫影像處理程式代替，除非使用者指定。

圖片要用在專案時，把產出保存或複製到該專案合適的素材資料夾，提供可取得的檔案位置；僅展示預覽時展示工具回傳圖片。不要只留下無法追蹤的工具暫存檔。修改既有圖保留原檔，回報新版本的位置。

## 交付與驗收表

| 素材 | 回報內容 | 實際檢查 |
| --- | --- | --- |
| 基準立繪 | 檔案位置、實際尺寸、格式、透明狀態 | 完整輪廓、五官肢體、固定配件、邊緣 |
| 獨立背景 | 檔案位置、畫幅、角色與文字預留區 | 無人物、地面透視、細節密度與留白 |
| 合成主視覺 | 檔案位置、使用的角色與背景版本 | 身份一致、光線、腳底接觸、主角辨識 |
| 表情變體 | 檔案位置、參照版本、本次改動 | 頭腳對齊、服裝一致、情緒清楚、透明 |

狀態使用「已生成並查看」「已生成但尚未完成檢查」「已提供 Prompt、待生成」等明確文字。只有實測的欄位才寫通過；無法檢查透明通道時標明未檢查，不能把看起來透明當成檔案驗證。

最後讓學員觀察一件容易判斷的事，例如「拿掉背景後，還認得出這位郵差嗎？」或「人物像真的站在郵局前嗎？」學員可以用生活語言要求修改，不需要重填整份企劃。
