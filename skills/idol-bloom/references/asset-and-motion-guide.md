# 素材與動態規格

本表協助把設計交給繪圖或實作的人。數量是起始建議，依指定成果刪減；單純角色企劃不需要全部製作。

先按本次範圍選素材。角色階段使用 [立繪與生圖指南](illustration-and-imagegen-guide.md)；需要背景時，再使用 [主題與場景設計](theme-and-scene-guide.md)接續。以下互動清單只適用於有原型需求的任務。

## 先選呈現方式

| 需要的成果 | 先準備什麼 | 完成後能驗證什麼 |
| --- | --- | --- |
| 靜態介紹／社群圖 | 主視覺、表情或構圖變體 | 外觀、文案與構圖一致性 |
| 只做角色立繪 | 角色設定、固定特徵與立繪規格 | 身份辨識、完整輪廓與素材可重用性 |
| 只做場景背景 | 現有角色摘要與圖像、場景用途和構圖 | 沿用角色，檢查背景畫風、光線與站位 |
| 完整角色視覺組 | 共同主題規格、透明立繪、獨立背景、合成圖與必要表情 | 角色身份、畫風、光線、透視與素材可重用性 |
| 網頁表情互動 | 待機圖、必要表情、文字與觸發規則 | 點擊或按鍵回應、狀態返回 |
| 姿勢圖片動畫 | 相同比例和構圖的姿勢序列 | 換幀、對齊與動作節奏 |
| 原圖局部變形 | 原圖、可動區域、幅度與遮擋限制 | 中立狀態、局部動態與極端姿勢 |
| 直播模型 | 依選定工具準備模型素材、綁定、追蹤與匯出 | 在指定工具與平台中的實際使用 |

圖片動畫、局部變形與直播模型的交付不同。不要為入門網頁作業自動增加模型製作，也不要把模型工作縮減為一張透明 PNG。

## 按階段列素材清單

角色初版可只做一張立繪；場景初版可只新增一張背景。互動原型可使用「一張主視覺＋兩種能表達個性的回應＋一個操作」。這些是不同範圍的提案，按需求選取；原型素材尚未完成時可用明確標示的佔位素材。

每個素材記錄：

| 欄位 | 填寫方式 |
| --- | --- |
| ID 與用途 | `hero-default`／首次介紹；`reaction-cheer`／收到鼓勵 |
| 格式與背景 | 依用途指定透明圖或完整場景；不要把棋盤格畫進透明圖 |
| 尺寸與比例 | 寫明輸出畫布與顯示比例，不將 Momo 的 3:4 當成通用規定 |
| 構圖 | 鏡頭方向、全身或半身、角色位置、邊緣安全留白 |
| 固定特徵 | 輪廓、五官、髮型、服裝、配件、畫風；表情變體另保留原光線 |
| 本次變動 | 表情、動作或服裝；清楚指定其中哪些改變 |
| 環境搭配 | 場景階段才補光源方向、時間、視角、角色站位與必要留白 |
| 對齊基準 | 表情圖用眼睛或頭部基準；站姿序列用身體中心與腳底基準 |
| 來源 | 使用者提供、原創繪製、生成或其他已確認可使用素材 |

來源記錄幫助後續找回素材；不自行替整組圖片宣告授權或商用保證。

## 可直接改寫的圖片 Prompt

```text
請依照我提供的角色主視覺製作一張表情變體。

角色固定特徵：〔輪廓、五官、髮型、服裝、代表配件〕。
畫風與光線：沿用參照圖。
本次只改：〔例如收到鼓勵後，抬頭微笑〕。
保留：原圖的〔構圖、比例、頭部位置、畫布尺寸〕。
輸出：〔尺寸與格式〕，〔透明背景／指定場景〕。
四肢與配件完整，邊緣保留〔指定留白〕，不加入文字與額外裝飾。
```

沒有主視覺時，先用已確認的角色與視覺規則建立第一張圖，再以它為後續變體基準。不要把多張各自生成的圖視為天然一致。

## 動作先寫目的，再寫變化

用一列描述一個動作：

| 觸發 | 角色目的 | 視覺回應 | 結束狀態 | 減少動態 |
| --- | --- | --- | --- | --- |
| 選擇鼓勵短句 | 表達被支持 | 換成開心表情，小幅點頭 | 保留回應文字，再回待機 | 直接換表情，文字仍可讀 |

進場、待機、互動、退場的速度與幅度應符合角色。附件的延遲或回彈服務動作方向，不讓所有部位同速擺動。

圖片序列須檢查背景、角色尺寸、配件與腳底對齊；有意的跳躍與轉身可改變位置，但不應因畫布構圖漂移而突然縮放。

局部變形先看中立狀態是否匹配原圖，再檢查轉向、快速反向、停止與回正。留意裂縫、重影、接縫、臉部拉扯與配件根部漂移。缺少被遮擋區域時，縮小動作幅度，或另行規劃補畫與模型素材。

直播模型的分層、變形器與參數需依實際工具與目標動作規劃；實作前核對官方匯入和匯出要求。沒有模型軟體或追蹤平台驗證時，明確交付為素材或規劃文件。需要來源與練習時，讀取 [參考庫](reference-library.md)中的 Live2D、VRM、GSAP 與 W3C 文件。
